# Loom 0.1.18

Loom 0.1.18 makes the CUDA Baseline viewer interactive and publishes live panel telemetry.

- CUDA Baseline window clicks, drags, scroll depth, and Ctrl/Super-click spawning now update the GPU interaction inputs.
- CUDA panel snapshots now include live FPS, CUDA frame time, CUDA memory, pressure, agent count, selected particle, active masks, and pointer state.
- Closing or disconnecting the panel no longer shuts down the CUDA viewer.
