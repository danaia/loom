# Loom 0.1.12

Loom 0.1.12 adds backend-specific installs: Metal on Apple Silicon and
CUDA-target CLI support on Linux RTX workstations.

## Highlights

- Publish separate GitHub release assets for `loom-metal-darwin-arm64` and
  `loom-cuda-linux-x86_64`.
- Install backend-specific commands with one curl installer:
  `loom-metal` for Metal and `loom-cuda` for CUDA.
- Keep backend installs side by side under `~/.loom-metal` and `~/.loom-cuda`,
  with optional control over the plain `loom` default symlink.
- Add `target cuda`, `extern cuda`, and `extern optix` source support for
  CUDA-target graph validation while native CUDA code generation remains future
  backend work.
- Document the CUDA/RTX architecture path for dense particles, sparse volumes,
  geometry, lighting, shadows, and RTX 5090-class benchmarks.
