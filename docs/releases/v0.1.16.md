# Loom 0.1.16

Loom 0.1.16 adds the Rust/Tauri project panel to the CUDA Baseline app package.

## Changes

- Launch the shared `loom-ui-panel` helper from the CUDA runtime when a project
  includes UI assets.
- Include `loom-ui-panel` in CUDA release packages.
- Prebuild the Baseline Vue UI during release packaging so installed CUDA users
  do not need npm dependencies to open the panel.
- Allow Linux source runs to use packaged `ui/dist` assets while skipping the
  macOS-only Rust project extension path.
- Publish initial CUDA panel telemetry and accept basic panel controls.

This keeps CUDA UI support intentionally narrow: it opens the Baseline panel and
connects the existing bridge protocol. Full project-extension parity, hot reload,
and richer CUDA telemetry remain next steps.
