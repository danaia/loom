# Loom 0.1.17

Loom 0.1.17 stabilizes the CUDA Baseline panel launch path.

## Changes

- Keep the CUDA viewer running if the project panel bridge disconnects.
- Verify the CUDA runtime launches `loom-ui-panel` with the packaged
  `baseline/ui/dist` assets.
- Preserve the CUDA Baseline viewer as the authority for app lifetime while the
  Linux panel bridge matures.
