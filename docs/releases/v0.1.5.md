# Pqo 0.1.5

Pqo 0.1.5 introduces `.lmp`, the self-contained project package format.

## Highlights

- `pqo build project.pqo` creates `project.lmp`.
- `pqo project.lmp`, `pqo check project.lmp`, and
  `pqo explain project.lmp` consume the packaged graph.
- External Metal resolves from the project directory and is copied into the
  package instead of being embedded as application-specific runtime code.
- Optional `src/runtime.rs` compiles to a target-specific extension using the
  versioned Pqo project ABI.
- The archive includes the primary `.pqo`, every referenced Metal source, Rust
  extension source, compiled extension, file inventory, target, and ABI version.
- `.lmp` is ZIP-compatible and can be extracted, edited, and rebuilt.

Marble Water is the first fully decentralized example. Its HUD, mouse and
keyboard behavior, shaders, and simulation kernels live inside its project
directory and distributable `.lmp`; the global runtime contains no
Marble-Water-specific implementation.

Running an existing `.lmp` requires only the Pqo runtime. Building a package
whose project contains `src/runtime.rs` additionally requires `rustc`.
