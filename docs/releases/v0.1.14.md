# Loom 0.1.14

Loom 0.1.14 adds a CUDA-native Baseline starter beside the existing Metal
Baseline project.

## Changes

- Add `baseline/baseline.cuda.loom`, a `target cuda` variant of the Baseline
  graph.
- Add `baseline/kernels/baseline.cu` with CUDA entries for interaction,
  particle motion, and render-stream projection.
- Add `baseline/shaders/baseline.optix.cu` as the named CUDA/OptiX view entry
  for the future RTX runtime path.
- Update CUDA installer output to point users at
  `loom-cuda check ~/.loom-cuda/baseline/baseline.cuda.loom`.
- Keep the existing Metal Baseline project as `baseline/baseline.loom`.
