# Loom 0.1.7

Loom 0.1.7 makes new Baseline projects immediately project-named.

## Highlights

- `loom new network` creates `network/network.loom` rather than
  `network/baseline.loom`.
- The starter's prebuilt `baseline.lmp` is removed, so a new project builds
  its own package with `loom build network.loom`.
- UI dependencies continue to be installed before the new project directory
  is finalized.
