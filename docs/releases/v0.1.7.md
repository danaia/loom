# Pqo 0.1.7

Pqo 0.1.7 makes new Baseline projects immediately project-named.

## Highlights

- `pqo new network` creates `network/network.pqo` rather than
  `network/baseline.pqo`.
- The starter's prebuilt `baseline.lmp` is removed, so a new project builds
  its own package with `pqo build network.pqo`.
- UI dependencies continue to be installed before the new project directory
  is finalized.
