# Loom 0.1.15

Loom 0.1.15 adds the first runnable CUDA Baseline app path on Linux.

## Changes

- Add `loom-cuda`, a narrow CUDA runtime crate for the Baseline starter.
- Compile `baseline/kernels/baseline.cu` to PTX with `nvcc` at run time.
- Load and launch Baseline CUDA kernels through the CUDA driver API.
- Present the CUDA render stream in a Linux window.
- Update CUDA installer output to show:
  `loom-cuda ~/.loom-cuda/baseline/baseline.cuda.loom`.

This is a first Baseline-only runtime slice. The general CUDA/RTX runtime,
OptiX renderer, project UI bridge, and high-density particle/volume execution
path still come next.
