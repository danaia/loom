# Pqo 0.1.11

Pqo 0.1.11 gives particles persistent, schema-driven agent metadata and makes
the Baseline starter safer to reuse with `pqo new`.

## Highlights

- Select particles from the Metal view or Agents window and edit their names,
  types, skill paths, and schema-defined metadata.
- Keep particle additions, removals, selection, and agent links synchronized
  across the viewer and both UI windows.
- Reset runtime particles, metadata, and chats to a single clean default
  particle without reverting project source code.
- Store particle and chat state in project-local `agentDB` files while excluding
  that runtime state and compiled `.pqo` caches from new projects and releases.
- Expose only the selected particle's metadata and attached skills to Pqo Agent
  unless the user explicitly requests a broader change.
