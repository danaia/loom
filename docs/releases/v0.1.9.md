# Loom 0.1.9

Loom 0.1.9 refreshes the Baseline starter used by `loom new` with the Loom
engineering skill, reference material, inspection helper, and editor guidance.

## Highlights

- New projects include the Baseline skills and tools needed to work with Loom
  systems and the native runtime.
- Baseline editor instructions cover Loom, Metal, runtime, and UI changes.
