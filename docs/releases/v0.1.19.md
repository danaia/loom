# Pqo 0.1.19

Pqo 0.1.19 completes the project rename from Loom to Pqo and restores the
Apple Silicon release installer with Pqo-native artifacts.

## Highlights

- Install the Pqo CLI and UI panel from `pqo-darwin-arm64` release assets.
- Author, validate, inspect, package, and run `.pqo` programs with the `pqo`
  command.
- Start new projects from the renamed Pqo baseline and examples.
- Keep generated Metal, validation diagnostics, execution graphs, and native
  rendering visible to AI coding agents.
