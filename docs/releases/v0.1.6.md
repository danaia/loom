# Pqo 0.1.6

Pqo 0.1.6 adds a release-backed Baseline project starter and coordinated
native project windows.

## Highlights

- `pqo new <project-name>` creates a new Baseline project in the current
  directory.
- Release packages include the portable Baseline starter, without development
  dependencies such as `node_modules`.
- Project-local window layout configuration snaps Controls to the left of the
  Metal viewer and Agents to its right, with linked movement.
- Closing any Pqo window or quitting with Command-Q closes the complete app.
