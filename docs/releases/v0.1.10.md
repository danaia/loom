# Pqo 0.1.10

Pqo 0.1.10 adds portable project instructions for coding agents and makes the
Pqo Agents window apply them by default.

## Highlights

- New projects include a root `AGENTS.md` with Pqo, Metal, runtime, and UI
  engineering rules for Codex and other agentic IDEs.
- The Pqo Agents window reads the active project's root `AGENTS.md` on every
  turn and treats it as authoritative project guidance.
