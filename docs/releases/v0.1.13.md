# Loom 0.1.13

Loom 0.1.13 fixes the CUDA CLI source-run path on Linux.

## Highlights

- Skip optional source-project UI and Rust extension preparation on Linux before
  reporting CUDA runtime availability.
- Let `loom-cuda check` and `loom-cuda explain` validate source projects without
  requiring Vue dependencies.
- Replace the misleading `vue-tsc: not found` failure with a CUDA-runtime status
  message for `loom-cuda SOURCE.loom`.
