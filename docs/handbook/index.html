HOW LOOM WORKS

Particles make choices. Fields carry information. Resolvers keep the world honest.

Three simple ideas create a system that can be large, fast, inspectable, and safe.

01 / PARTICLES

Individual identity and state

A particle can represent a cell, crystal unit, robot, wallet, task, or point in a fluid.

  • position + velocity
  • energy + memory
  • identity + role
02 / FIELDS

Information spread through space

Fields are the shared environment: weather, sound, scent, pressure, danger, or demand.

  • nutrient + injury
  • heat + pressure
  • risk + attention
03 / RESOLVERS
REQUEST✓UPDATE

A referee for every action

An agent may request a move. A resolver checks whether it is legal before state changes.

  • enough energy?
  • room available?
  • permission granted?
ONE TICK IN THE LIFE OF AN AGENT

Sense. Decide. Request. Resolve. Update.

The split between requesting and resolving matters. It keeps one ambitious particle from rewriting the world, colliding with a neighbor, or spending energy it does not have.

  2. 02Decidechoose a local response

WHY THE GPU MATTERS

One complicated job? Call the CPU. One simple job, a million times? That is GPU territory.

Think of a CPU as a few expert chefs. A GPU is a giant kitchen with thousands of stations, all preparing the same kind of step at once.

Loom keeps state on the GPU: it stores, updates, measures, and renders the particles without hauling a million records back and forth every frame.

CPU A few complex workers
GPU Thousands of parallel workers

WHAT EXISTS TODAY

A clear boundary builds trust

Loom now writes its first GPU math. Metal remains the advanced escape hatch.

Loom v0 is real, but it is not a finished general-purpose language. Native Loom kernels now type-check scalar and vector arithmetic and generate Metal. Complex kernels can still use explicit packaged Metal while the language grows.

WHAT ELSE COULD GROW?

Change what a particle represents, and the same ideas open very different doors.

These are directions, not finished products. The visual behavior only matters when it corresponds to real state and measurable rules.

ROBOT SWARMS

Coordination without a single point of failure

Robots sense obstacles, battery, nearby teammates, communication, and work demand—then reorganize when one fails.

  • particle → robot
  • field → danger / demand
LIVING DATA

Data that becomes a changing structure

Wallets, processes, or documents become agents. Real relationships drive clustering, tension, flow, and deformation.

  • particle → record
  • field → risk / attention
ARTIFICIAL MATERIALS

Surfaces and structures with local repair rules

Explore fracture, erosion, heat response, adaptive structures, and materials that reorganize after damage.

  • particle → material unit
  • field → heat / stress
DIGITAL WORLDS

Worlds that simulate change instead of playing it back

Forests adapt, terrain erodes, creatures develop, and structures recover from their actual local state.

  • particle → cell / grain
  • field → water / nutrient
AGENT AUTOMATION

Many small workers, shared limits, visible coordination

Research, coding, monitoring, or planning agents request work while resolvers enforce permissions and resources.

  • particle → task agent
  • field → urgency / confidence

10

HONEST LIMITS

A substrate for emergence is not a shortcut around hard science.

Loom is not yet…

  • a biologically exact simulator
  • an atom-by-atom material model
  • a replacement for every game engine
  • a finished general-purpose language
  • automatically intelligent

The difficult work remains…

  • choosing useful local rules
  • avoiding runaway feedback
  • measuring global structure
  • validating behavior against reality
  • making complex systems understandable
Loom provides the machinery for emergent systems. It does not automatically discover the right rules.

THE LARGER VISION

Software as a living process.

Loom is an experiment in programming systems that are not fully drawn in advance. Instead, agents perceive, fields communicate, rules constrain, structures emerge, and systems sometimes repair themselves.
